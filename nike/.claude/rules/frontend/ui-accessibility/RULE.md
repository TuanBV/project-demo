# UI and Accessibility Rules
- Interactive elements use buttons/links with keyboard support and visible focus.
- Inputs have associated labels and accessible validation messages.
- Modals trap focus, support Escape, and restore focus.
- Tables expose correct headers and responsive alternatives.
- Verify main flows at mobile and desktop widths.
