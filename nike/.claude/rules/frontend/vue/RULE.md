# Vue Rules
- Use Vue 3 Composition API consistently and remove obsolete compiler-macro imports.
- Components receive typed/validated props and emit documented events.
- Keep API calls out of presentational components.
- Provide loading, empty, success, validation, and error states.
- Do not leave inert links, debug logs, copied placeholder tables, or hidden failures.
